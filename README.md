# Hallonkriget

Sommaren 1958 står ett hallonsnår exakt på tomtgränsen mellan Torpet och Storgården. Det blir krig.

Ett realtidsstrategispel med Knights and Merchants ekonomi och strid, i en bondgårdsvärld i bilderboksstil. Byggt i Godot 4.4 med C#, med en fristående deterministisk simuleringskärna och låstegsmultiplayer över IP.

## Kom igång

Du behöver:

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Godot 4.4 .NET](https://godotengine.org/download/archive/4.4.1-stable/) (välj ".NET"-versionen)

Köra testerna:

```
dotnet test
```

Öppna spelet: starta Godot, välj Importera och peka på `game/project.godot`.
